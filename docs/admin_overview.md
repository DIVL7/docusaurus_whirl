# Vista General del Administrador - Whirl

Este documento proporciona una visión general de las funcionalidades disponibles para el administrador dentro de la plataforma Whirl.

## Panel de Control (Dashboard)

El panel de control es la página principal después de iniciar sesión. Muestra un resumen de la actividad reciente, estadísticas clave y accesos directos a las secciones más importantes.

-   **Estadísticas Rápidas:** Número de usuarios, cursos activos, módulos completados, etc.
-   **Actividad Reciente:** Últimos registros, cursos añadidos, etc.
-   **Accesos Directos:** Enlaces rápidos a la gestión de usuarios, cursos y reportes.

## Gestión de Usuarios

Permite administrar todas las cuentas de usuario en el sistema (técnicos y otros administradores).

-   **Crear Usuarios:** Añadir nuevos técnicos o administradores.
-   **Editar Usuarios:** Modificar información existente, roles y permisos.
-   **Eliminar Usuarios:** Desactivar o eliminar cuentas.
-   **Buscar y Filtrar:** Encontrar usuarios específicos o grupos.

## Gestión de Cursos

Esta sección se dedica a la creación y administración del contenido formativo.

-   **Crear Cursos:** Definir nuevos cursos, descripciones, objetivos.
-   **Gestionar Módulos:** Añadir, editar y organizar los módulos dentro de cada curso (lecciones, videos, quizzes).
-   **Asignar Cursos:** Asignar cursos específicos a técnicos o grupos.
-   **Ver Progreso:** Monitorear el avance de los técnicos en los cursos asignados.

## Gestión de Módulos de Curso

Detalle sobre la administración de los componentes individuales de un curso.

-   **Tipos de Contenido:** Añadir texto, imágenes, videos, PDFs, quizzes.
-   **Organización:** Estructurar el contenido de forma lógica dentro de cada curso.
-   **Actualizaciones:** Modificar contenido existente.

## Reportes

Generación de informes sobre el uso de la plataforma y el progreso de los usuarios.

-   **Reportes de Progreso:** Informes detallados sobre el avance de los técnicos.
-   **Reportes de Actividad:** Uso de la plataforma, tiempo de conexión, etc.
-   **Reportes Personalizados:** Posibilidad de generar informes con filtros específicos.

## Configuración (Implícita)

Aunque no haya una sección explícita, el administrador maneja configuraciones generales como:

-   Roles y permisos.
-   Ajustes generales de la plataforma.
